
# React Fundamentals Lab (Next.js + TypeScript)

## Setup

```bash
npm install
npm run dev    # start app at http://localhost:3000
npm test       # run unit tests
```

## What to implement
- Fill all TODOs in `app/components/*`, `lib/hooks/useRenderCount.ts`, and `app/page.tsx`.
- Ensure tests in `__tests__/app.test.tsx` pass.

## Notes
- Uses App Router (`app/page.tsx`).
- Uses Jest + React Testing Library via `next/jest` preset.
- Uses `@/` path alias mapped to repo root.
