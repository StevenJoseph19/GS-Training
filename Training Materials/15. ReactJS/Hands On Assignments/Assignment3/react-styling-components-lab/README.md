
# Styling Components — Lab (Next.js + TypeScript)

### Objectives
- Apply **global styles** via `app/globals.css`.
- Use **CSS Modules** for component-scoped styles.
- Demonstrate **inline styles** for dynamic visual hints (discouraged for large apps).
- Implement a **theme toggle** that switches global classes.

### Tasks
- Complete all `TODO` markers in components and styles.
- Make tests in `__tests__/styling.test.tsx` pass.

### Run
```bash
npm install
npm test
npm run dev
```
