
# Application Anatomy — Lab (Next.js + TypeScript)

### Objectives
- Create and compose function components using the **App Router** (`app/page.tsx`).
- Practice **default** vs **named** module exports and **barrel** files.
- Move data/utilities out of components into `lib/` modules.

### What to implement
- Fill all `TODO` markers in components and utils.
- Ensure tests in `__tests__/anatomy.test.tsx` pass.

### Run
```bash
npm install
npm test
npm run dev
```
