Start Zookeeper
==============
bin/zookeeper-server-start.sh config/zookeeper.properties


Start Apache Kafka
=====================
wsl --distribution Ubuntu

bin/kafka-server-start.sh config/server.properties

WSL2 IP (for server.properties=>advertised listener)
==================================================
hostname -I

OR
===

The PowerShell "Quick Finder"
==========================
wsl hostname -I

Update "advertised listeners" in config/server.properties
========================================================
sudo nano config/server.properties

Then stop and restart only Kafka server
=========================================================

Check if IPv6 is enabled or disabled, from a terminal window: 
===========================================================

cat /proc/sys/net/ipv6/conf/all/disable_ipv6 

If it is '0'
==============
sudo sysctl -p -- If it is already set in configuration file. This will activate the settings.

Otherwise
=========
sudo nano /etc/sysctl.conf
===> 
net.ipv6.conf.lo.disable_ipv6=1
net.ipv6.conf.default.disable_ipv6=1
net.ipv6.conf.all.disable_ipv6=1

Verify Connectivity (Windows side)
Before writing any Spring Boot code, check if Windows can actually see Kafka. 
Open PowerShell on Windows and type:
=========================================================
Test-NetConnection -ComputerName 172.22.x.x -Port 9092 
# Test-NetConnection is a PowerShell-specific tool.

OR
===
telnet 172.22.x.x 9092
# Windows Command Prompt
# If the connection succeeds, the screen will go blank (connected).

Script to override advertised listeners
======================================================
# Create a simple shortcut script inside their Ubuntu home folder.

# Create the file: nano start-kafka.sh

# Paste the command:

#!/bin/bash
IP=$(hostname -I | awk '{print $1}')
echo "Starting Kafka with IP: $IP"
~/kafka_2.13-3.0.0/bin/kafka-server-start.sh ~/kafka_2.13-3.0.0/config/server.properties \
--override advertised.listeners=PLAINTEXT://$IP:9092

Make it runnable: chmod +x start-kafka.sh

Type ./start-kafka.sh 

# Run your PowerShell test again: 

Test-NetConnection -ComputerName 172.22.x.x -Port 9092.

# zookeeper must be running first.

List Topics 
=============

bin/kafka-topics.sh --list --bootstrap-server 172.22.45.6:9092
                                             <-advertised listener - same as in config/server.properties -->

Delete Topic
================
bin/kafka-topics.sh --delete --topic notifications --bootstrap-server  172.22.41.230:9092


Display messages in topic
======================
bin/kafka-console-consumer.sh --bootstrap-server 172.26.250.220:9092 --topic notifications --from-beginning

Diagnostics
===============================

 netstat -an | grep 9092

If netstat shows LISTEN but Java fails: It's a Windows Firewall or IP/Network issue.

If netstat shows NOTHING: It's an Ubuntu/Kafka startup issue (likely ZooKeeper isn't running or server.properties has an error).
